# Dataset

This folder is intended to store the dataset for the disease prediction project.

**Source**: The dataset used is the UCI Heart Disease dataset (specifically, the processed Cleveland dataset).
**Access**: The dataset is downloaded programmatically using pandas directly from the UCI Machine Learning Repository or via the `ucimlrepo` package during notebook execution. 

We do not unnecessarily commit the raw dataset to GitHub to keep the repository clean and avoid data duplication, since it's a publicly available dataset that can be reliably fetched via code.
